## 🧩 Installation
```
git clone https://github.com/t1ltxz-gxd/popcorn.git 
cd popcorn
cargo build
```

## 🚀 Launch
Run `cargo run` or `make start`.

## 🧪 Tests
Run `cargo test` or `make test`.
